# Jayavel Stores (ஜெயவேல் ஸ்டோர்ஸ்)

A modern, high-performance website for **Jayavel Stores**, showcasing heritage cookware, brass & bronze vessels, god statues, and handcrafted teakwood furniture.

## Features

- **Heritage Showcase**:
  - Traditional brass, bronze, and stainless steel kitchenware
  - Handcrafted god statues (Ganesha, Murugan, Lakshmi, Ayyappan, Brass Pooja Statues)
  - Authentic Chettinad & Salem teakwood and steel furniture (Bero, Diwan, Sofa, Bed, Oonjal, Pooja Mandapam, Gas Stove Stand)
- **Direct WhatsApp Orders & Enquiries**:
  - Automatically includes product name and live product image URL in WhatsApp messages for instant recognition
- **Bilingual Interface**: Seamless switching between English and Tamil (தமிழ்)
- **Live Search**: Instant product discovery across categories in both languages
- **Static HTML + Next.js App**: Compatible with both static hosting and full-stack Next.js deployment

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language Support**: TypeScript

## Getting Started

Run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
